# SOZORO（そぞろ）

**デモ: https://sozoro.opd-hackathon-b.workers.dev**
（スマホで開いてください。位置情報の許可が要ります。ホーム画面に追加するとアプリとして開きます）

上野・浅草に集中した観光客を、**混んでいる瞬間に、30分で戻れる範囲へ散らす**アプリ。
都知事杯オープンデータ・ハッカソン2026 提出作品。

入口は「散歩しませんか」ではなく **「今、上野公園は混んでいます」**。
不満が起きた瞬間に、気分だけ選ばせて、**行き先を伏せたまま**3案を出す。
着いて初めて、そこが何かわかる。

## 画面の流れ

```
① ホーム         地図に主要ランドマークを混雑3段階で色分け。混んでいるときだけ誘う
② 気分と時間     食べる / 街に触れる / 体験する ＋ 次の予定までの時間
③ 針路を設定中   最低1.6秒は見せる（速すぎると「選ばれた感」が消えるため）
④ 運命の針路     3案。モザイク画像＋ティーザー文＋距離・徒歩分・戻れる時刻
⑤ 旅が始まる     演出
⑥ ナビ           方角と残り距離だけ。経路は出さない
⑦⑧ 到着          名前・画像・解説が開く。下に周辺スポット一覧
```

## 設計上の要点

| 要点 | 理由 |
|---|---|
| 入口は「混雑の提示」 | 散歩したくて使う観光客はいない。トリガーは欲望ではなく不満 |
| 混んでいなければ誘わない | 常に「混んでいます」と言うアプリは信用されない。平常時は別の文言を出す |
| 気分は選ばせるが場所は伏せる | 完全に伏せると不安。全部見せると単なる店検索になる |
| 3案・別々の町字から | 1案だと押し付け。同じ方向に3案出すと選択肢に見えない |
| 距離・徒歩分・戻れる時刻を必ず出す | 「帰ってこられるか分からない」不安を数値で潰す＝**安全な範囲のランダム** |
| 加盟店は別枠にしない | 別枠は広告枠になる。同じ抽選に重みだけ載せるので嘘にならない |
| 丁目代表点の座標は使わない | 文化財CSVの座標は丁目単位。そのままだと「あと〇〇m」が嘘になる |

## 混雑をどう推定しているか

**リアルタイムの混雑データは公開されていない**（東京都カタログを検索しても使えるものは無い）。
そこでオープンデータから統計的に推定する。

```
混雑スコア ＝ エリア基礎値 × 時間帯係数 × 曜日係数 × 季節係数 × 天候係数
```

| 係数 | 出どころ | 状態 |
|---|---|---|
| エリア基礎値 | 台東区 来訪者アンケート3,147件「残念だったこと＝人の多さ（混雑）」の回答率 | **実測** |
| 季節係数 | デジタル観光統計 台東区 月別来訪者数（2025年） | **実測** |
| 時間帯係数 | 台東区「観光バス混雑予想カレンダー」の記述（10〜14時が高い／15時以後は空く） | 二次情報 |
| 曜日係数 | 公式の根拠が取れず **1.0で無効化** | ODPT待ち |
| 天候係数 | 係数は仮。天気の取得は気象庁 予報API（鍵不要） | 仮 |

**実測と仮置きは `docs/data/congestion.json` の `provisional` / `source` で区別している。**
ODPT の駅時刻表が届いたら、時間帯と曜日を一次データに差し替える。

エリア基礎値の実測値: 上野 38.3% / 浅草 36.4% / 谷中 24.1% / 浅草橋 16.4%。

## 作りの説明

```
docs/     配信する静的ファイル（Cloudflare の assets・GitHub Pages の公開元）
worker/   API（Cloudflare Workers）。D1 を引く
db/       D1 のスキーマと種SQL（公開しない）
```

| ファイル | 役割 |
|---|---|
| `docs/index.html` | 画面7枚を `hidden` の切り替えで出し分ける |
| `docs/app.css` | ライト・ダーク両対応。屋外で片手で見る前提の大きめの文字 |
| `docs/js/main.js` | 画面遷移と状態管理 |
| `docs/js/congestion.js` | 混雑推定。デモ用の日時上書きもここ |
| `docs/js/map.js` | 地図。**ライブラリをここに閉じ込めてある**（差し替えを安くするため） |
| `docs/js/api.js` | API呼び出し・ティーザー生成・戻れる時刻の計算 |
| `docs/js/geo.js` | Haversine 距離 / 方位角 |
| `docs/js/compass.js` | 端末の向き。iOS は `requestPermission` + `webkitCompassHeading` |
| `docs/sw.js` | アプリシェルのみキャッシュ。目的地データはキャッシュしない |
| `worker/index.js` | `/api/destinations`（3案・伏せる）と `/api/nearby`（到着後・伏せない） |

地図は **Leaflet + 国土地理院 淡色地図**。鍵も課金も要らない。
地理院タイルはラスタなので、ベクタ用の MapLibre は使っていない（gzip 42KB 対 230KB、WebGL不要）。

## 動かす

```sh
yes | wrangler d1 execute sozoro --local --file=db/schema.sql
yes | wrangler d1 execute sozoro --local --file=db/seed.sql
wrangler dev
# → http://localhost:8787
```

`--local` なので本番には触らない。手元の DB を引いて API まで動く。

画面だけ見たいなら `cd docs && python3 -m http.server 8080` でもよいが、
`/api/*` は動かないので3案は出ない。

**チームで開発するときは [TEAM.md](TEAM.md)。** デプロイと D1 の手順は [DEPLOY.md](DEPLOY.md)。

### 手元のブラウザで試す

現在地がないと何も起きないので、Chrome DevTools で位置を上書きする。

1. DevTools → 右上の ⋮ → More tools → **Sensors**
2. Location に緯度経度を入れる（例: 谷中 `35.7205, 139.7654`）

**混雑カードが出ないときは、ホーム画面の「デモ用に日時を変える」で 11月23日 12:00 などにする。**
8月は最も空く月（係数0.871）で、15時以降はスコアが落ちるため。

## データ

目的地は **7,864件**（active 7,547件）。すべて台東区・荒川区のオープンデータ由来。

| レイヤー | 件数 | 主なデータ |
|---|---:|---|
| 食べる | 7,141 | 食品衛生営業施設一覧 |
| 街を見る | 116 | 文化財一覧（**場所ごとに集約**）・名所史跡・観光施設 |
| 体験する | 203 | 江戸創業事業所顕彰・手作り工房マップ・伝統工芸職人・銭湯 |
| 静かに歩く | 87 | 公園・児童遊園 |

文化財は「1件＝1目的地」にしていない。190件のうち159件は寺の所蔵物（美術工芸品）で
行っても見られないため、**場所（寺社）単位に集約**している。

座標・画像・解説は Wikipedia と Wikimedia Commons（いずれも CC BY-SA）で補強した。
**別の場所の写真を出さないよう、名前が一致したものしか採っていない。**

| レイヤー | 提示できる件数 | うち画像あり |
|---|---:|---:|
| 街を見る | 130 | **95（73%）** |
| 静かに歩く | 87 | 13 |
| 体験する | 197 | 7 |
| 食べる | 7,136 | 3 |

個人商店の写真は Wikipedia にも Commons にも無いため、「体験する」「食べる」は
ほぼ画像が無い。ここは手作業か現地撮影で足すことになる。

ティーザー文は全件に付けてある（`scripts/write_teasers.py`）。
**正体は明かさず**「［具体的な事実］＋［施設の種別］」の形にそろえ、
有名な場所は型で作ると弱いので50件あまりを手で書いた。

### データを作り直す

> **注意: 加工用のスクリプトとデータは、このリポジトリには入っていない。**
> ひとつ上のフォルダ（`東京都ハッカソン2026/`）に `scripts/` と `data/` があり、
> そこを作業ディレクトリにして実行する。このリポジトリに入っているのは
> **配信するアプリと、D1 のスキーマ**だけ。`db/seed.sql` は生成物なので追跡していない。

```sh
cd ..                                   # 東京都ハッカソン2026/ へ
sh scripts/fetch_opendata.sh            # 元データを data/raw/ に取得
python3 scripts/collect_destinations.py # 正規化 → data/destinations.csv
python3 scripts/enrich_wikipedia.py     # 文化財の場所を Wikipedia と照合
python3 scripts/find_images.py          # 画像を探す（Commons まで見るので約50分）
python3 scripts/write_teasers.py        # ティーザー文を作る
python3 scripts/build_congestion_model.py
python3 scripts/build_seed_sql.py       # → SOZORO/db/seed.sql
```
